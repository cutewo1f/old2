## 01 — Introduction

**old2** is an improved continuation of my previous [old](https://github.com/cutewo1f/old) theme.

While the original focused on bringing back the old Discord appearance, this version takes things further by refining the overall layout, adjusting individual UI elements, and introducing additional customizations.

The goal is simple: bring back the familiar Discord experience while making it feel more complete and comfortable to use.

## 02 — What's Included

| Feature | Description |
|:--|:--|
| **Classic UI** | OldCord styling and visual adjustments |
| **Reverted Server List** | Restores the older server list appearance |
| **Custom Typography** | Pretendard font integration |
| **Sidebar Refinements** | Adjusted positioning, spacing, and layout |
| **User Panel** | Reworked bottom user section |
| **Cleaner Interface** | Removes selected unnecessary UI elements |
| **Chatbox Adjustments** | Improved alignment and spacing |
| **Animations** | Subtle transitions for menus and interactions |
| **Profile Styling** | Additional profile gradient customization |

## 03 — Installation

<sub>REQUIREMENTS · DISCORD + VENCORD</sub>

### QuickCSS Installation

1. Open Discord.
2. Navigate to **Settings → Vencord → QuickCSS**.
3. Add the following import at the very top of your QuickCSS file:

```css
@import url("https://raw.githubusercontent.com/cutewo1f/old2/main/oldthe2");
```

4. Save your changes.
5. Reload Discord if necessary.

That's it!

### Manual Installation

1. Open [`oldthe2`](https://github.com/cutewo1f/old2/blob/main/oldthe2).
2. Copy the entire CSS file.
3. Open **Settings → Vencord → QuickCSS**.
4. Paste the contents into your QuickCSS editor.
5. Save and reload Discord.
